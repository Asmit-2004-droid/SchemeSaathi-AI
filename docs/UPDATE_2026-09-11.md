# SchemeSaathi repair update - 11 September 2026

This update builds on the existing prototype in the supplied ZIP. The original archive and source catalogue were preserved. The target remains scheme discovery for marginalized entrepreneurs in the MoSJE context supplied by the user; it is a student service, not a government approval portal.

## Changes

- Search navigation now opens a real catalogue search. Multiword queries, category filters, paginated results, document/application details, retry and empty states work against the API. Invented category counts were removed.
- Chat uses a pure-Python lexical index, removing the native SciPy import that Windows Application Control blocked on this machine. Explicit scheme names/acronyms rank before broad synonyms. Short follow-ups retain context, and the browser limits history to the API's 20-turn contract.
- Typed chat has an explicit language selector. Non-English questions and replies use server-side Bhashini translation. Browser microphone recognition follows the selected language. Translation failures produce an actionable error instead of an unrelated English answer.
- Bhashini discovery selects the requested task and language, honors supported voice gender and requests WAV output. Empty/invalid recordings are rejected. A TTS failure retains the text answer; audio can be replayed or stopped.
- Support provides a formal prefilled email request, phone contact, issue-writing guidance, dated private tickets and staff replies. The floating support link is hidden on the support page.
- SMS preference is read from the database and survives reload. Provider readiness checks include the public HTTPS website URL. Existing staff-only campaigns use an approved MSG91 flow, explicit consent and duplicate-batch reservation. No real SMS was sent.
- Decimal family-income parsing is corrected. Open-ended income bands do not establish compliance with an upper limit. Missing document lists no longer invent requirements.

## Data review

The 653-row catalogue has no complete record of freshness or provenance. Structural findings are in DATA_AUDIT.json: two missing document lists and three HTTP source URLs, with MoSJE-related records flagged for manual review. This audit is not proof that the other records are accurate.

The current search index results for NBCFDC are inconsistent: the General Loan page reports an annual-family-income ceiling of Rs 3 lakh while its Loan Flyer reports Rs 5 lakh. Do not silently overwrite the rule table with either figure without obtaining current applicable guidelines. No monetary benefit or eligibility rule was certified as current in this update.
